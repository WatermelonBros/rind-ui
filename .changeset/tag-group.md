Add Tag Group: a grid of tags (or a named group when empty) with roving focus over both arrow pairs, selection, link tags, removal by the remove button or Delete/Backspace with focus moved to a neighbour and a polite announcement, a removal hint for keyboard and screen-reader users, and a data mode; `getTagGroup`, `tag-group.css`. Contracts can locate by a set of roles (`By.role([...])`).
