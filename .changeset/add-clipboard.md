Clipboard: a copy button or a read-only field with a copy button. The result comes from the write (`copying` → `copied` | `error`), announced politely; the Trigger's name never changes; a copy of the whole Input counts. Code Block shares its copy logic. Testing: `getClipboard`, and `Part.copySelection()` / `Part.selectRange()` in the contract environment. Theme: `clipboard.css` in the field family.
