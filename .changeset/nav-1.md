Add Breadcrumbs and Pagination. Breadcrumbs: a named navigation landmark with an ordered list, the current page marked with `aria-current="page"` (a span when it has no `href`), separators hidden from assistive technology, and collapsing with an Ellipsis; `getBreadcrumbs`, `breadcrumbs.css`. Pagination: a page-range model with boundaries and siblings, controls as buttons or real links (`getPageHref`), a page clamped when the count shrinks, page-size changes that keep the first item visible; `getPagination`, `pagination.css`.
