Table of Contents: a navigation landmark of anchor links with one current section, chosen by a reading line (`offset`, `ratio`) and the end of the scroll range, `data-visible` on sections in view, a followed link held through its jump, focus moved to the heading for keyboard and screen-reader users, a window or container scroll root, a list that keeps the current item in view, and an Indicator positioned by CSS variables. Core: `core/dom/reading-position` (`collectHeadings`, `measureReading`, `readingPosition`). Testing: `getTableOfContents`; a link to an element of the same document now jumps instead of being cancelled. Theme: `table-of-contents.css`.
