New package `@rind-ui/solid` (`solid-js` ≥ 1.9): the same machines, ARIA and drivers as
`@rind-ui/react`, ported one component at a time (this release: Toggle, Button, Separator, Kbd, Badge, Heading, Label, Link, Skeleton, Progress, Meter, Image, Avatar, Alert, Toggle Group, Fieldset, Field, Text Field, Checkbox, Checkbox Group, Switch, Radio Group, Segmented Control, Collapsible, Accordion, Tabs, Toolbar, Breadcrumbs, Pagination, Rating, Slider, Number Input, Pin Input, Splitter, Stepper, Timeline, Table of Contents, Scroll Area, Marquee, QR Code, Clipboard, Code Block, Form, Form Toggle, File Upload, Tag Group, Listbox, Grid List, Tree View, Sortable, Table, Popover, Tooltip, Hover Card, Dialog, Drawer, Toast, Tags Input, Menu, Context Menu, Menubar, Navigation Menu, Select, Combobox, Tour, Calendar, Date Field, Color Picker, Image Viewer, Image Cropper, Message Thread, Streaming Message, Reasoning, Prompt Input). Parts are Solid
components with reactive props, `on<Value>Change` callbacks and a `render` function for element
substitution; each entry ships JSX under the `solid` condition and DOM-compiled JavaScript as
`default`.
