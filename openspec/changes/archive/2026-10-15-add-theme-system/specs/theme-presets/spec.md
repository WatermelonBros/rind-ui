## Purpose

Defines the two ready-made presets, `calm` and `crisp`, how they are produced, and the
Storybook brand switcher and contrast report that show every component under every
preset and sample brand.

## ADDED Requirements

### Requirement: Presets Are Builder Inputs

`calm` and `crisp` SHALL each be a set of brand inputs fed to `defineTheme`; their
CSS SHALL be generated by the builder in strict mode and checked in, and a test SHALL
fail when the checked-in CSS differs from a fresh build. A consumer SHALL be able to
start from a preset with `defineTheme({ name, extends: "crisp", … })`.

| Input | `calm` (default) | `crisp` |
|---|---|---|
| accent | `oklch(0.52 0.19 268)` | `oklch(0.55 0.2 255)` |
| neutral | `oklch(0.5 0.01 270)` | `oklch(0.5 0.005 250)` |
| danger | `oklch(0.55 0.2 27)` | `oklch(0.55 0.21 27)` |
| warning | `oklch(0.75 0.15 75)` | `oklch(0.75 0.16 75)` |
| success | `oklch(0.6 0.14 150)` | `oklch(0.55 0.15 150)` (0.58 cannot reach 4.5:1 with white or black text) |
| fontSans | system UI stack | system UI stack |
| fontMono | system mono stack | system mono stack |
| fontSize | `0.875rem` | `0.875rem` |
| radius | `0.5rem` | `0.25rem` |
| density | `1` | `0.875` |
| motion | `1` | `0.75` |
| borderStrength | `0.2` | `0.6` |

#### Scenario: Presets pass strict validation

- **WHEN** both presets are built in strict mode
- **THEN** no contrast pair fails in light or dark

#### Scenario: Extending a preset

- **WHEN** `defineTheme({ name: "acme", extends: "crisp", accent: "#0a7d55" })` is built
- **THEN** its radius, density and border strength equal `crisp`'s

### Requirement: Preset Files

`@rind-ui/theme` SHALL export `calm` on `:root` and on `[data-rind-theme="calm"]` from
its main entry, and `crisp` as `@rind-ui/theme/presets/crisp.css` scoped to
`[data-rind-theme="crisp"]`.

#### Scenario: Switching preset by attribute

- **WHEN** both preset files are loaded and `data-rind-theme` changes from `calm` to
  `crisp` on a subtree
- **THEN** components in that subtree switch to crisp radius, density and borders

### Requirement: Storybook Renders Themed Components

The Storybook preview SHALL load `@rind-ui/theme` with `calm` as default and SHALL
offer toolbar globals for brand (`calm`, `crisp`, and sample brands including a
light-yellow and a near-white accent built in adjust mode), scheme (system, light,
dark) and tone, applied as attributes on the story root. Every component story SHALL
render the themed component.

#### Scenario: Brand switcher

- **WHEN** the brand global is set to `crisp`
- **THEN** the story root carries `data-rind-theme="crisp"` and every story renders
  with crisp tokens, including portalled content

#### Scenario: Axe in every brand

- **WHEN** the story test run executes for each preset in light and dark
- **THEN** every story passes axe colour-contrast

### Requirement: Contrast Report

Storybook SHALL include a contrast report page that renders, for the selected brand,
every checked pair from the builder report in light and dark, with ratio,
requirement, pass/fail and any adjustment applied.

#### Scenario: Adjusted sample brand

- **WHEN** the report is opened for the light-yellow sample brand
- **THEN** it lists the adjusted tokens with their original and adjusted colours and
  every pair passes
