## REMOVED Requirements

### Requirement: Same Behaviour As Dialog Unless Stated

**Reason**: Alert Dialog is no longer a component of its own: a Dialog with `role="alertdialog"` is the confirmation (user decision: no duplicate components).

**Migration**: the requirement moves to the `dialog` capability as "Alert Dialog Role — Same Behaviour As Dialog Unless Stated"; `AlertDialog.*` becomes `Dialog.*` with `role="alertdialog"` on the Root, `getAlertDialog(target, anchor)` becomes `getDialog(target, { ...anchor, role: "alertdialog" })`.
