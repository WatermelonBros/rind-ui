# Where other libraries are ahead

Every point where another headless library beats rind-ui, as written on the site's
[/compare](https://rind.watermelon-studio.it/compare/) page, with what we will do about it.
A gap closes when the action is done and the compare page no longer needs to say it.

| Gap | Ahead | Action | Status |
|---|---|---|---|
| Production record | React Aria, Radix, Base UI | Ship Reado on rind-ui; collect external adopters; publish a "used by" list only with permission | open |
| API stability | React Aria, Radix, Base UI, Ark | 1.0 with a written semver and deprecation policy (Get started → Versioning) | done: 1.0 published (1.2.0 now) |
| Translations | React Aria (30+ languages) | Translate every component's messages for the most used locales, generated from one catalogue | open |
| Frameworks beyond React | Ark (React, Vue, Solid, Svelte); Reka, Bits, Kobalte for one framework each | React, Vue, Svelte, Solid and Angular published on the framework-free core (1.2.0) | done |
| Drag and drop depth | React Aria | Research note on React Aria's drag and drop (keyboard and screen-reader moves across collections); extend Sortable and Tree View to cross-collection moves | open |
| Ecosystem and community answers | Radix | Copy-paste skins (crisp, juicy, calm) as a CLI-installable kit; answer questions in public; examples for common stacks | open |
| Team size and backing | React Aria (Adobe), Base UI (company-backed), Ark (Chakra team) | Second maintainer; contribution guide; good-first-issue labels | open |
| Screen-reader verification with real assistive technology | React Aria | Documented manual passes per component (NVDA, JAWS, VoiceOver macOS and iOS, TalkBack), published with each release | open |
| Components only others ship | see [components.md](components.md) `todo` rows | Build them in inventory order | open |
