# @rind-ui/testing

Official test drivers for rind-ui components, for Testing Library and Playwright.

```sh
pnpm add @rind-ui/testing
```

```ts
import { getAccordion } from "@rind-ui/testing"
```

Part of [rind-ui](https://github.com/WatermelonBros/rind-ui): see the main README and
`docs/components/` for the components and their APIs.
