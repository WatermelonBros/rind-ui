# QR differential fixtures

`differential.json` holds module matrices produced by two reference encoders, generated once
offline on 2026-10-16 and committed (add-qr-code, design.md open questions):

- `uqr` 0.1.3 (npm), `encode(value, { ecc, maskPattern, border: 0, boostEcc: false })`
- Nayuki's QR-Code-generator v1.8.0 (`typescript-javascript/qrcodegen.ts`, MIT),
  `QrCode.encodeSegments(QrSegment.makeSegments(value), ecc, 1, 40, mask, false)`

Every case was generated by both and kept only where the two matrices are identical. Neither
package is a dependency of this repository; the generator ran in a scratch directory outside
it. Strings are encoded without ECI by both references, so the tests compare them with
`encodeQr(value, { ecc, mask, eci: "none" })`.

Cases: digits, alphanumeric, an ASCII URL, UTF-8 text, binary data and the version-1 byte
boundary at every level, the eight forced masks at level Q, and 2953 bytes at version 40-L.
