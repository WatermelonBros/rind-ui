# @rind-ui/theme

Optional white-label theme for rind-ui, with a typed, contrast-checking theme builder.

```sh
pnpm add @rind-ui/theme
```

```ts
import "@rind-ui/theme"
```

Part of [rind-ui](https://github.com/WatermelonBros/rind-ui): see the main README and
`docs/components/` for the components and their APIs.
