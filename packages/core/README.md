# @rind-ui/core

Framework-agnostic state machines, DOM utilities and contracts for rind-ui headless components.

```sh
pnpm add @rind-ui/core
```

```ts
import { buttonConnect } from "@rind-ui/core"
```

Part of [rind-ui](https://github.com/WatermelonBros/rind-ui): see the main README and
`docs/components/` for the components and their APIs.
